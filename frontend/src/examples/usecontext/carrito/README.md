## Ejemplo previo con useContext

Esta carpeta conserva la implementacion original del carrito con `useContext`.

Se deja como referencia academica para documentar el aporte previo del equipo y
compararlo con la nueva implementacion usando Redux Toolkit.

Archivos:

- `CartContextLegacy.jsx`: contexto global original del carrito
- `CarritoPageUseContextExample.jsx`: pagina del carrito consumiendo ese contexto

Estos archivos no forman parte del flujo activo de la aplicacion.
